# Archivo de la Ciudadela

Explorador interactivo de personajes de Rick and Morty. Proyecto académico individual de **Lirio Berenice Chuc Yam (@LirioYam)**, desarrollado con asistencia de IA y exclusivamente mediante el editor web de GitHub.

## Plan de desarrollo

1. Estructura semántica en `index.html`.
2. Diseño adaptable en `style.css`.
3. Consulta real con `fetch()` en `script.js`: imágenes y descripción de hasta 20 personajes por página.
4. Búsqueda, filtros, favoritos persistentes y manejo de errores.
5. Publicación y pruebas en GitHub Pages.
6. Reto posterior: orden alfabético en una rama y un Pull Request.

## Fuente de datos

[Rick and Morty API: documentación oficial](https://rickandmortyapi.com/documentation). Los personajes se obtendrán de la API; no se escribirán datos de personajes manualmente.
